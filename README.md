# 🛡️ Cybersecurity Incident Impact Dashboard

##  Overview
The Cybersecurity Incident Impact Dashboard is an interactive Power BI project that analyzes cybersecurity incidents and their financial, operational, and business impact. The dashboard provides insights into attack trends, financial losses, compromised records, downtime, and company risk using interactive visualizations.

---

##  Objectives

- Analyze cybersecurity incidents from 2021–2025
- Identify the most common attack vectors
- Measure financial losses and operational impact
- Compare public and private company incidents
- Monitor incident trends over time
- Provide business insights for cybersecurity decision-making

---

## Dashboard Features

- KPI Cards
  - Total Incidents
  - Total Financial Loss
  - Records Compromised
  - Companies Affected
  - Average Downtime
  - Average Stock Return
  - Average Recovery Days

- Interactive Charts
  - Attack Vector Analysis
  - Public vs Private Companies
  - Incident Trend by Year
  - Downtime Distribution
  - Severity vs Downtime Analysis
  - Top Companies by Financial Loss
  - Country-wise Incident Map
  - Incident Details Table

---

##  Key Insights

- 778 cybersecurity incidents analyzed
- $55.2 Billion total financial loss
- 1.6 Billion records compromised
- 750 companies affected
- Ransomware was the leading attack vector
- Cyber incidents increased steadily from 2021 to 2025
- Average recovery time: 110 days
